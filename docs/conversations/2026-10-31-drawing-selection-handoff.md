# 그림 단위 선택·편집 — Claude 인계

2026-10-31 · 사용자 확인 및 저장소 업로드 요청. 구현 담당은 Claude. 이 문서는 요구사항이며 구현 완료 보고가 아님.

## 문제의 정확한 뜻

사용자는 ‘레이어 단위 선택이 안 된다’고 설명했고, 그림을 독립된 대상으로 선택·이동·크기 조절·편집하는 기능이 필요하다는 설명에 동의했다. Codex는 앞서 이를 ‘그리기 모드로 다시 들어가기 어려움’으로 좁게 이해했다. 도구 재진입 버튼만으로 해결되지 않는다.

## 승인된 동작

- 그림 클릭: 해당 그림의 선택 테두리와 크기 조절 손잡이 표시.
- 드래그: 선택한 그림만 이동.
- 모서리 드래그: 비율 유지 크기 조절.
- 선택한 그림만 삭제·복제·앞뒤 순서 변경.
- 더블클릭 또는 ‘그림 편집’: 해당 그림 내부 선 추가·지우기. 모바일에서도 명시적인 편집 버튼 제공.
- 바깥 클릭: 선택 해제하고 글쓰기 계속.
- 텍스트·사진·붙인 정보 입력 시 그리기 도구가 입력을 가로채지 않음.

## 그림 묶음

한 번 새 그리기를 시작해서 마칠 때까지의 선을 그림 하나로 묶는다. 기존 그림 편집은 같은 묶음을 수정하고, 새 그림 시작은 별도 묶음을 만든다. 모든 선을 각각 별도 레이어로 노출하지 않는다. 내부에서 필요한 선을 다루되, 본문에서는 그림 단위로 조작한다.

기존 post.ink는 블록 기준 좌표의 선 데이터다. 그룹 식별자·이동·크기·겹침 순서 및 기존 데이터 호환 방법은 최신 코드를 읽고 설계한다. 과거 데이터에 없던 묶음 경계를 정확히 복원할 수 있다고 가정하지 말 것. 기존 그림을 유실하거나 임의 삭제하지 않는다.

## 디자인과 구현 경계

본문은 기존 블로그처럼 편하게 쓴다. 레이어 목록을 항상 노출하지 않고 선택했을 때만 필요한 조작을 보여 준다. 기존 글꼴·색 변수·글자/알약 버튼 규칙 유지. PC 마우스와 모바일 터치 모두 지원. 위젯 편집이나 범용 디자인 도구로 범위를 넓히지 않는다.

## 완료 검증

1. 그림 두 개를 만들고 하나만 선택·이동·크기 변경·복제·삭제할 수 있다.
2. 두 그림이 겹쳐도 대상을 선택하고 앞뒤 순서를 바꿀 수 있다.
3. 그림 뒤에 텍스트를 입력한 다음 기존 그림을 다시 선택·편집할 수 있다.
4. 내부 편집에서 선을 추가·지워도 다른 그림은 바뀌지 않는다.
5. 선택 해제 뒤 본문 입력, 사진 조작, 붙인 정보 입력이 정상이다.
6. 저장·임시저장 복원·다시 열기 후 그림 위치·크기·그룹·순서가 유지된다.
7. 기존 저장 그림과 빈 문단 위 그림이 보존된다.
8. PC와 모바일에서 검증하고 실제 기기 미검증은 별도로 표시한다.
