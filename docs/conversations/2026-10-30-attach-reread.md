# 2026-10-30: 글 먼저, 필요한 정보만 붙이고 다시 읽기

## 승인한 방향
자유로운 장문 작성 → 필요한 정보만 선택적으로 붙이기 → 여러 기준에서 같은 원문 다시 보기.
기존 블로그 디자인을 유지하며 위젯은 이번 범위에서 제외한다.

## 구현
main d26ca3c 위에서 기존 클로드의 붙이기/검색을 보존했다.
- 후보에 붙인 뒤의 쓸모를 안내.
- 첫 입력칸 외에는 선택적으로 펼침. 값이 있던 항목은 다시 편집할 때 표시.
- 같은 정보의 기록을 날짜·제목·원문 일부로 모아 보고 원문으로 이동.
- 모음 구성과 클릭 시 현재 공개 권한 확인. 본문·공개 범위 변경 없음.
- 양식/항목의 정확한 값으로 연결. 책/장소 식별 DB, 의미 추정, 거래 실행은 구현하지 않음.

## 검증 및 한계
JS 구문 검사, diff 공백 검사, 핵심 로직 테스트 통과.
PC에서 글 작성, 붙이기, 공개/비공개 저장, 관련 글 모음, 원문 열기 확인.
방문자 모음에서 비공개 글이 제외됨 확인.
390px 모바일 폭에서 입력, 더 적기 펼치기, 모음 확인. 실제 iOS 키보드 미검증.
로컬 Playwright Chromium이 없어 전체 UI 자동 회귀시험은 미실행. 기존 위젯 sandbox 시험 통과를 주장하지 않는다.
미리보기 live reload가 JS의 닫는 body 문자열에 삽입되는 문제는 시험용 사본에서 이스케이프해 확인했다. 제품 원본에는 해당 변경 없음.
