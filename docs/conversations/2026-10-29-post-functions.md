# 글의 사용자 정의 기능 — 합의와 첫 구현

## 사용자와 정한 방향

- 익숙한 블로그 디자인과 자유로운 장문을 유지한다.
- 글의 목적이나 카테고리를 먼저 고르게 하지 않는다.
- 필요한 경우 속성과 기능을 붙여 쓰임을 확장한다.
- 사용자는 기능의 이름·항목을 직접 구성하고, 내 기능으로 저장해 다른 글에서도 사용한다.
- 향후 위젯 피드에서 가져오거나 코드로 제작한 기능도 글과 공간에 연결할 수 있다. 이번 구현에는 포함하지 않는다.

## 이번 구현

- 글쓰기 하단 `기능 추가`: 물건 정보, 독서 기록, 직접 만들기, 저장한 내 기능.
- 텍스트·숫자·날짜·선택 항목 추가/이름 변경/삭제.
- 구성 창의 적용·취소는 작성 중인 글에만 반영된다. 글 저장은 기존 발행/저장 버튼을 사용한다.
- `내 기능으로 저장`은 별도 저장 동작이며 항목 구성만 보관한다. 입력한 값은 다른 글로 복사하지 않는다.
- 내 기능에서 지워도 이미 글에 붙인 기능은 유지된다.
- 글의 공개 범위를 따라 정보를 표시한다. 개별 항목의 비공개 설정은 제공하지 않는다.
- 임시저장, 백업, 기존 서버의 글/개인 문서 저장 경로에 포함된다. 서버 스키마 변경은 없다.

## 아직 구현하지 않은 것

- 참여 신청 접수와 타인의 응답, 결제, 외부 코드 실행.
- 기능 공개 공유 및 위젯 피드 연동.
- 기능의 속성으로 검색·피드 필터링.

정보를 입력하고 보여주는 단계와 실제 행동을 처리하는 단계는 구분한다.
