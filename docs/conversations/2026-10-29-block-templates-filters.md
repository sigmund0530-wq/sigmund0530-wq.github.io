# 블록: 템플릿과 검색 기준

사용자 결정: 위젯 논의는 제외하고 블록에 집중. 블록은 일종의 필터이자 템플릿이다. 자유로운 본문을 쓰면서 정보 묶음을 선택적으로 붙이고, 나중에 같은 항목으로 글을 찾는다. 해당 방향 구현을 요청했다.

기존 붙이기 흐름을 확장했다. 중고 판매 양식(물건/가격/상태)을 추가하고, 기존 검색에 블록 선택과 항목 조건을 연결했다. 사용자 제작 구성도 지원한다. 기능별 전용 검색 화면이나 판매/예약 실행 동작은 만들지 않았다.

구성 식별자와 항목 키를 보존해 재사용과 이름 변경을 지원한다. 저장한 구성은 입력값 없이 복사한다. 기존 구성 수정이 다른 글을 변경하지 않는다. 공개 가능한 글에서만 검색 결과와 필터 항목을 구성한다.

현재 필터는 이 기기에 불러온 게시글 범위다. 서버 전체 검색, 필터 공유, 제작자 생태계는 이번 구현 범위가 아니다. main 배포와 분리된 codex/record-blocks 브랜치에서 작업했다.
