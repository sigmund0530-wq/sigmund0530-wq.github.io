# 그리기·파일 드롭·더 적기 개선

요청: 그림 뒤 텍스트를 쓰고 다시 그림을 수정하기 어려움. 붙이기를 할 때 그리기 도구가 남음. 파일을 드래그로 넣고 싶음. 더 적기는 가격/판매 상태 외에 필요한 항목을 골라 붙일 수 있어야 함.

변경: 그림 수정 진입점과 편집 세션 내 undo/redo 보존, 입력 전환 시 도구 종료, 그림만 있는 문단 저장 보존, 선분 지우개. 편집 폼에 이미지/음성 드롭. 양식별 추가 항목 선택과 사용자 정의 텍스트/숫자/날짜/선택 항목. 기존 본문 중심 디자인과 Claude의 모아보기 유지.

검증: build/구문/공백 검사, 기존 pf_reread 및 새 editor_inputs Node 검사 통과. 브라우저에서 그리기→붙이기 한 번 클릭, 도구 닫힘, 브랜드 추가, 보관 방법 사용자 정의 선택지 추가, 임시저장 복원 확인.

제한: Python 전체 테스트는 playwright 패키지 부재로 미실행. OS 파일 드롭과 실제 휴대폰 터치 검증 남음. PDF 등 일반 파일 첨부 미지원. 그림 이동/개별 선 선택은 이번 범위 아님.
