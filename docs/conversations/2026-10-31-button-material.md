# 버튼 재질 시안

사용자는 초기 iPod 사진을 제시하며 버튼 하나하나가 이런 느낌이기를 원했고 진행을 승인했다. 매끈한 백색 표면, 얇은 틈, 낮은 두께, 눌릴 때 내려앉는 반응을 적용한 독립 시안이다.

파일: ../design/button-material.html

평평한 형태/입체 형태 전환, 밝은/어두운 화면, 선택 유지, 키보드 포커스, reduced-motion 대응을 포함한다. 제목과 본문은 입력 가능하나 저장하지 않는다. 도구와 저장/발행 버튼은 상태 시연이며 실제 앱 기능을 실행하지 않는다.

기존 앱 원본과 Claude의 그림 레이어 작업은 변경하지 않았다. 현재 디자인 규칙의 그림자 배제는 본문/카드에 유지하며, 이번 시안은 사용자가 새로 요청한 버튼 재질 실험이다. 최종 서비스 전체 적용은 시안 평가 후 진행한다.

HTML 파싱 및 JavaScript 구문 검사 통과. 브라우저 미리보기는 자동 승인 검토의 사용량 한도 거절로 실행하지 못했다. 실기기 렌더링·터치 및 시각 검증 완료라고 보고하지 않는다.
