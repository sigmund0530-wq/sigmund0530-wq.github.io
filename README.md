# 무가당 (MUGADANG)

날것의 개인 기록을 남기는 블로그·SNS (베타)

- 사이트: https://sigmund0530-wq.github.io
- 기기별 미리보기: https://sigmund0530-wq.github.io/preview.html

**작업하는 AI·개발자는 [AGENTS.md](AGENTS.md)를 먼저 읽어 주세요.**

- `src/app.html` — 앱 원본 (고치는 곳)
- `build.py` — 원본으로 `index.html`·`preview.html` 만들기
- `server/` — Supabase 데이터베이스·파일 규칙
- `tests/` — 자동 시험 (`sh tests/run.sh`)

> 이 저장소는 공개예요. 사용자 글이나 비밀 키(service_role, sb_secret, DB 비밀번호)를 절대 넣지 않아요.
