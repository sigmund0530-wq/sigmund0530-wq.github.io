# 무가당 글자공방 — 동작하는 독립 제작기 v1.0

**기능을 실제로 작동하게 연결한 독립 실험판입니다.** 글자 모양을 직접 수정하고 작업 파일을 저장·복원하며, 전체 한글 11,172자를 포함하는 **진짜 TTF / WOFF2 폰트**를 생성합니다. 무가당 본 서비스의 계정·데이터·글쓰기 편집기는 수정하지 않았습니다.

## 실행 (PC, Windows/macOS/Linux)

Python 3.11+ 설치 후 압축을 풀고 **Windows는 `start-windows.bat`**, macOS/Linux는 `start-mac-linux.sh`를 실행하면 됩니다. 수동 실행은 해당 폴더에서:

```sh
python -m pip install -r requirements.txt
python server.py
```

브라우저에서 http://127.0.0.1:8766 를 여세요. 생성 작업은 컴퓨터에서 실행되며 서버를 종료하면 편집 화면의 파일 생성 기능을 사용할 수 없습니다. 편집 중 내용은 브라우저에 저장되고, 언제든 `작업 파일 저장`으로 JSON 백업을 받을 수 있습니다. HTML 파일만 열면 그림 편집과 JSON/SVG 내보내기는 되지만 TTF/WOFF2 생성은 되지 않습니다.

## 완성된 기능

- **67개 자모 부품**: 초성 19개, 중성 21개, 받침 27개 개별 편집
- **자모 변경 전파**: 초성 한 개를 수정하면 관련 한글 588개에 반영, 중성은 532개, 종성은 399개
- **글자 단위 예외 편집**: 사용자가 고른 한글 음절을 단독으로 수정. 이 음절은 자모 자동 변경에서 분리되며 `이 글자 초기화`로 복귀 가능
- 점 직접 이동 / 점 추가·삭제 / 새로운 획 그리기 / 원·선·사각형 / 획 복제·반전·회전 / 간단한 2차 곡선 / 획 닫기 / 획 정렬 / 전체 초기화
- 되돌리기·다시하기 / 굵기·가로폭·획 끝 조절 / 예문 미리보기 / SVG 내보내기
- 브라우저 임시 저장 / JSON 내보내기·가져오기
- **TTF·WOFF2 파일 생성 및 다운로드**: 만든 파일을 다시 불러 실제 폰트로 예문 출력
- 한글 11,172자 음절 + 공백과 기본 문장 부호. 라틴·숫자·한자 등의 글리프는 현재 포함하지 않으므로 지원하는 응용프로그램의 대체 글꼴에 의존

## 검증된 사항

- `python -m unittest discover -s tests -p 'test_studio.py' -v`: 코드 생성·자모 전파·개별 보정·WOFF2·입력 오류 검증
- `python -m unittest discover -s tests -p 'test_http.py' -v`: 서버·생성 API·실제 파일 반환 검증
- `python tests/test_browser.py`: Chromium 브라우저 UI 상호작용과 TTF·WOFF2 내려받기 검증 (실험 환경의 보안 정책으로 로컬 URL 직접 접속은 차단돼 `set_content` 및 테스트용 API 대체 호출로 확인. 실제 로컬 서버 API는 test_http.py로 별도 검증)
- 생성 파일을 fontTools로 재열어 11,172자 `cmap` 전수 검사

## 품질에 관해

이 파일은 **정말로 설치할 수 있는 글꼴**이지만, 현재 기본 자모는 직접 만든 단순한 모노라인 기하학 디자인입니다. 완성된 상업용 서체와 비교해 조형 균형, 글자 간 시각적 간격, 가변 축, 힌팅, 고급 조판 기능은 부족합니다. TTF 파일을 만든다는 것과 전문 서체 품질을 보장한다는 것은 서로 다른 주장입니다. 모든 사용자가 고급 수준의 결과물을 자동으로 얻는 기능은 구현되어 있지 않습니다.

## 기술과 라이선스

- UI: 순수 HTML/CSS/JavaScript. 기존 무가당 편집기 소스 `src/app.html`은 변경하지 않음.
- 폰트 생성: Python `fontTools` (MIT) 및 `Shapely` (BSD-3-Clause), 사용자 제작 자모로 컴포지트 TrueType 구성
- 관련 오픈소스 전문 편집기 [Fontra](https://github.com/fontra/fontra)와 [fontra-rcjk](https://github.com/fontra/fontra-rcjk)는 검토했지만 **GPL-3.0 코드 자체는 복사·결합하지 않았음**.
- `fonteditor-core`는 브라우저 전용으로 이전할 때 참고할 대안이며 **현재 빌드 엔진에 포함되지 않음**.
- 현재 서버는 인증·과금·사용량 제한이 없는 **개발용 localhost 서버**. 인터넷에 직접 공개하면 안 됨.

## 무가당 연동 전에 할 일

1. 실제 사용자들이 만든 다양한 자모에서 깨지는 글자와 예외 규칙 확인
2. 파일 저장·다운로드 보안과 서버 부하 정책을 갖춘 API 개발 또는 브라우저 내 빌드 엔진으로 전환
3. 발행된 글의 폰트 버전 보존, 브라우저 지원 폴백, 모바일 Safari 사용성 확인
4. 카카오톡·iOS·Android: TTF를 설치 가능한 앱/시스템에 적용할 수 있더라도 **메시지에 폰트가 자동 포함되지는 않음**. 받는 사람에게 동일 디자인을 일반 텍스트 복붙으로 전파하는 것은 불가능

## 저장소 연결

서버형 실험 앱이므로 기존 GitHub Pages에서는 폰트 생성 API를 실행할 수 없습니다. 본 서비스 배포나 병합은 별도 검토가 필요합니다.
