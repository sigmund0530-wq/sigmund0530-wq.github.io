글자공방 사용법

① 기본 서체를 고르고, 문장을 직접 입력해 느낌을 확인하세요.

② 글자 다듬기에서 원하는 글자를 누르고 윤곽을 선택한 뒤 점을 드래그하세요. 빈 공간을 클릭해 점을 추가하는 건 ‘점 찍기’ 도구를 사용합니다.

③ ‘완성하기’에서 TTF 또는 WOFF2를 받으면 글자 디자인이 실제 파일에 반영됩니다.

작업은 이 브라우저에 자동 보관되지만 브라우저 데이터를 지우면 사라질 수 있습니다. ‘작업 파일 내보내기’로 JSON도 저장하세요.

원본의 윤곽을 이용한 파생 글꼴은 원본 라이선스 의무를 지켜야 합니다. 채팅의 일반 텍스트에 임의의 폰트가 자동으로 붙지는 않아요.
