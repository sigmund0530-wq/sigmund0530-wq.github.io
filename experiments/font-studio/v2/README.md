# 무가당 글자공방 v2 — 고품질 한글 베이스 · 실제 글리프 편집

이 프로젝트는 독립 실행하는 **로컬 퍼스트 폰트 제작 서비스**입니다. 무가당 본문 편집기와 사용자 데이터는 수정하지 않습니다. 설치 가능한 TTF와 웹용 WOFF2를 생성합니다. 글꼴 자체는 이 저장소·ZIP에 번들하지 않습니다.

## 제공하는 경험

1. **글꼴 만들기**: SIL OFL 기반 공개 한글 글꼴에서 시작. 문장 미리보기, 전체 글자 폭(75~125%), 기울기(-14~14°), 자간(-70~140 폰트 단위) 및 간단 프리셋.
2. **글자 다듬기**: 기존 글꼴의 **실제 TrueType 윤곽**을 직접 불러와서 편집. 곡선(on/off-curve) 점 이동, 점 추가/삭제, 윤곽 추가(사각형/원), 윤곽 이동/삭제, 되돌리기/다시하기. 예문에서 글자 선택. **수정한 글자만** 다른 모양으로 저장.
3. **완성하기**: 실제 TTF / WOFF2 생성. WOFF2를 브라우저에 다시 불러오는 정확한 미리보기. 수정 데이터를 포함한 JSON 프로젝트 백업/복원, 여러 프로젝트 및 브라우저 자동 저장.

수정하지 않은 한글 11,172자는 전문 서체 원본의 완성도 높은 윤곽을 유지하며, 별도로 수정한 글자는 그대로 실제 파일에 반영됩니다. 폰트 디자이너 수준의 품질·가변 폰트·힌팅까지 자동 보장하는 것은 아닙니다.

## 실행하기

**Python 3.11 이상, 인터넷 연결 1회 필요**(공식 오픈소스 글꼴 다운로드):

```bash
python -m pip install -r requirements.txt
python bootstrap_fonts.py
python server.py
```

이후 브라우저에서 http://127.0.0.1:8770 에 접속합니다. Windows는 `start-windows.bat`, macOS/Linux는 `start-mac-linux.sh`를 사용할 수 있습니다. 서체 파일은 `runtime/fonts/`에만 저장되며 저장소의 `.gitignore` 대상입니다.

> **주의:** 이 서버는 `127.0.0.1` 전용이고 공개 인터넷 배포용이 아닙니다. 본 서버는 로그인·운영자 관리·사용량 계측·악성 업로드 검사 등 다중 사용자 배포 인프라를 제공하지 않습니다.

## 사용 중 데이터 보존

프로젝트는 브라우저의 localStorage에 저장하고, 서버에 사용자 문서나 글리프 데이터를 영구 저장하지 않습니다. 브라우저 데이터 정리 시 소실될 수 있으므로 **작업 파일 내보내기(JSON)**를 사용하세요. 프로젝트별로 완성형 글리프 점·곡선 편집 데이터가 남아 재편집할 수 있습니다. 여러 브라우저 간 자동 동기화는 없습니다.

## 라이선스·저작권

- Python fontTools: MIT, Brotli: MIT, 기타 런타임 라이선스는 각 패키지의 배포조건을 따릅니다.
- **다운로드되는 원본 폰트:** Google Fonts 공개 저장소의 나눔고딕·나눔명조·고운돋움·고운바탕 등, 각 SIL Open Font License 1.1을 확인하세요. 원본 저작권 표기 및 OFL 메타데이터는 수정본 안에 유지됩니다.
- **예약된 글꼴명 사용 금지:** 본 도구는 이름을 자동으로 `MGD [사용자 지정 이름]`으로 바꾸고 'Nanum/나눔/Naver/네이버/Gowun/고운' 등 보호된 명칭을 차단합니다. 단, 사용자가 지정한 이름이 다른 권리를 침해하지 않도록 해야 합니다.
- **수정 글꼴은 SIL OFL 조건 적용** 및 단독 판매 금지. 비독점 원본 글꼴을 약간 수정했다고 저작권 독점권이 생기는 게 아닙니다.
- 본 도구 자체의 소스는 원본 폰트 바이너리를 포함하지 않습니다.

## 테스트

```bash
python -m unittest discover -s tests -p 'test_*.py' -v
python tests/test_browser.py
```

테스트 커버리지:
- 한글 11,172자 cmap 유지 / TTF·WOFF2 왕복, 원본 윤곽 보존, 개별 윤곽 수정 반영, 스타일 메트릭·저작권 표기 유지.
- 서버의 실제 HTTP 생성·잘못된 요청 거절·외부 출처의 요청 차단.
- Chromium(데스크톱 1280px / 모바일 390px)의 탭, 서체 크기 조절, 글리프 윤곽 수정, 실제 TTF 다운로드.

브라우저 자동화 환경의 로컬 접속 제한 때문에 Playwright UI 테스트에서 API 요청을 Python 브리지로 대체했습니다. **서버 실제 HTTP 경로는 test_http.py가 독립적으로 검증**합니다. 브라우저 운영 환경의 실제 폰트 다운로드와 iOS Safari 기기 검증은 아직 별도 확인이 필요합니다.

## 남은 출시 필수 과제

- 로그인·사용자별 저장·서버 인증·남용 제한, 정식 도메인/호스팅·HTTPS, 공개 운영 모니터링
- 원본 서체 재배포/라이선스 문구의 배포 흐름 고도화
- iOS Safari/Android 실제 터치·드래그·파일 다운로드·설치 테스트
- 많은 사용자 프로젝트·대형 글리프의 성능 테스트 및 프로젝트 버전 관리 개선
- 합성 자모를 편집해 11,172자에 자동 전파하는 기능은 **이 고품질 베이스 편집 경로에는 아직 없음**. 기존 v1 자모 실험기와 별개이며, 두 모드를 연결했다고 주장하지 않습니다.
