# 무가당 글자공방 v3 — 직접 그리는 벡터 캔버스 · 고품질 한글 폰트

이 프로젝트는 독립 실행하는 **로컬 퍼스트 폰트 제작 서비스**입니다. 무가당 본문 편집기와 사용자 데이터는 수정하지 않습니다. 설치 가능한 TTF와 웹용 WOFF2를 생성합니다. 글꼴 자체는 이 저장소·ZIP에 번들하지 않습니다.

## 제공하는 경험

1. **글꼴 만들기**: SIL OFL 기반 공개 한글 글꼴에서 시작. 문장 미리보기, 전체 글자 폭(75~125%), 기울기(-14~14°), 자간(-70~140 폰트 단위) 및 간단 프리셋.
2. **자유롭게 그리기**: 1000-em SVG 캔버스에서 마우스·터치·펜으로 직접 획을 그리는 **브러시**, 기존 윤곽을 실제로 깎는 **지우개**, 드래그로 만드는 **사각형·타원**, 점 세 개 이상으로 만드는 **닫힌 펜 경로**. 모두 서버에서 실측 벡터 부울 연산 후 폰트 윤곽으로 반영 (CSS 효과나 이미지 저장이 아님).
3. **전문 편집**: 기존 글꼴의 **실제 TrueType 윤곽**을 직접 불러와 on/off-curve 점을 조절하고 개별 윤곽을 이동·복제·반전·회전·확대/축소. 캔버스 이동·60~300% 확대, 되돌리기·다시하기, 빈 도화지에서 시작, 원본 복구. **수정한 글자만** 개별 보정하며 다른 글자는 원본 품질 유지.
4. **완성하기**: 실제 TTF / WOFF2 생성. WOFF2를 브라우저에 다시 불러오는 정확한 미리보기. 수정 데이터를 포함한 JSON 프로젝트 백업/복원, 여러 프로젝트 및 브라우저 자동 저장.

수정하지 않은 한글 11,172자는 전문 서체 원본의 완성도 높은 윤곽을 유지하며, 별도로 수정한 글자는 그대로 실제 파일에 반영됩니다. 폰트 디자이너 수준의 품질·가변 폰트·힌팅까지 자동 보장하는 것은 아닙니다.

## 실행하기

**Python 3.11 이상, 인터넷 연결 1회 필요**(공식 오픈소스 글꼴 다운로드):

```bash
python -m pip install -r requirements.txt
python bootstrap_fonts.py
python server.py
```

이후 브라우저에서 http://127.0.0.1:8770 에 접속합니다. Windows는 `start-windows.bat`, macOS/Linux는 `start-mac-linux.sh`를 사용할 수 있습니다. 서체 파일은 `runtime/fonts/`에만 저장되며 저장소의 `.gitignore` 대상입니다.

> **주의:** 이 서버는 `127.0.0.1` 전용이고 공개 인터넷 배포용이 아닙니다. 본 서버는 로그인·운영자 관리·사용량 계측·악성 업로드 검사 등 다중 사용자 배포 인프라를 제공하지 않습니다.

## 사용 중 데이터 보존

프로젝트는 브라우저의 localStorage에 저장하고, 서버에 사용자 문서나 글리프 데이터를 영구 저장하지 않습니다. 브라우저 데이터 정리 시 소실될 수 있으므로 **작업 파일 내보내기(JSON)**를 사용하세요. 프로젝트별로 완성형 글리프 점·곡선 편집 데이터가 남아 재편집할 수 있습니다. 여러 브라우저 간 자동 동기화는 없습니다.

## 작업 방법 · 조작

- **직접 그리기**: `✎ 자유 그리기`를 선택하고 캔버스에서 드래그하세요. 획 두께는 슬라이더로 조절합니다. `◫ 지우개`는 영역을 지우고, 원·사각형은 드래그한 범위만큼 그려집니다.
- **펜 도구**: 점을 세 개 이상 차례로 찍은 뒤 **Enter** 또는 시작점을 다시 누르면 완성됩니다. Esc는 취소입니다.
- **윤곽 수정**: `↖ 점 선택`으로 곡선 점을 조정하고, `✥ 윤곽 이동`으로 한 윤곽을 통째로 이동합니다. 오른쪽에서 복제·반전·회전·크기를 조절합니다.
- **캔버스 탐색**: `✋ 손`으로 패닝하고 `＋/−/맞춤`으로 배율을 변경합니다. 단축키 B 브러시, E 지우개, V 선택, M 윤곽 이동, P 펜, H 손.
- **실제 반영**: 그린 결과는 TrueType 윤곽선에 반영됩니다. `완성하기`에서 TTF/WOFF2로 받으며, JSON 작업 파일로 이후 수정할 수 있습니다.
- **제약**: 같은 글자 내에서 겹치는 획은 하나의 윤곽으로 합쳐집니다(독립 레이어 아님). 그리기에서 만들어진 윤곽은 직선점으로 저장되므로 이후 곡선 정밀 조절은 사용자가 직접 해야 합니다. 개별 글자 256개까지 별도 보정 가능.

- iOS Safari/Android 실제 터치·드래그·파일 다운로드·설치 테스트
